# Alcolizer LE5 Script

Alcolizer LE5 is a standalone FiveM script that simulates a handheld breathalyser device, inspired by equipment used by Australian police.

The goal of this project was to create a focused, realistic, and performant interactive tool that could be easily configured and deployed on live servers.

---

## Features

- Interactive and realistic user interface
- Performance-conscious design  
  - ~0.00ms idle  
  - ~0.02ms while in use
- Highly configurable behaviour
- Fully standalone (no external dependencies)

---

## Technical Overview

This project demonstrates:

- Lua-based interaction systems
- UI-driven gameplay tools
- Client-side performance optimisation
- Configuration-first design
- Clean separation between visuals, logic, and configuration

The script was built to function reliably in real multiplayer environments rather than as a prototype or proof-of-concept.

---

## Installation

1. Add the resource to your server’s resources folder  
2. Configure settings to suit your server  
3. Start the resource via your server configuration
